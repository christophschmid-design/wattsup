WattsUp, Datenschutz

WattsUp ist eine private Trainings-App für eine einzelne Person. Sie wird nicht verkauft und nicht an andere weitergegeben.

Welche Daten verarbeitet werden

  • Aktivitäten und Trainingswerte aus Strava
  • Termine im Google-Kalender „Training“, die die App liest, anlegt oder löscht
  • Eine Datei im versteckten App-Ordner von Google Drive, um Einstellungen und Einträge zwischen den eigenen Geräten abzugleichen
  • Für die Wochenplanung werden Trainingsdaten an die Claude-Schnittstelle von Anthropic gesendet

Wo die Daten liegen

Zugangsschlüssel und Daten werden nur auf den Geräten des Nutzers und in seinem eigenen Google Drive gespeichert. Es gibt keinen eigenen Server. Der Quellcode auf GitHub enthält keine persönlichen Daten.

Google-Daten

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung. Google-Daten werden ausschließlich für die oben genannten Funktionen verwendet und nicht weitergegeben.

Widerruf

Der Zugriff kann jederzeit in der App unter „Verbindungen und Kosten“ getrennt oder im Google-Konto unter Sicherheit → Drittanbieter-Apps entfernt werden.
